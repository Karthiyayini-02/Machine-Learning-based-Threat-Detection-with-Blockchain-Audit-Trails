# Machine Learning Based Threat Detection with Blockchain Audit Trails

### Network Intrusion Detection with Tamper-Resistant Security Logging

## 📌 Project Overview

This project presents a **machine learning-based network threat detection system** designed to identify potentially malicious network traffic and maintain tamper-resistant audit records of detected security events.

The system uses the **Random Forest classification algorithm** and the **KDD Cup 99 dataset** to classify network traffic into normal and malicious categories.

To improve the integrity of security records, blockchain-based hash verification is incorporated to maintain an auditable record of detected threats.

> **Project Status:** ✅ Completed Research Project

## 🔍 Key Components

### 1. Network Traffic Analysis

The system analyzes network traffic features to identify patterns associated with normal and potentially malicious connections.

### 2. Data Preprocessing

The network traffic dataset is processed to prepare the features required for machine learning-based classification.

The preprocessing stage includes appropriate data preparation and transformation before model training.

### 3. Random Forest Classification

A **Random Forest classifier** is used to classify network traffic.

The model learns patterns from the training data and predicts whether network traffic belongs to a normal or malicious category.

### 4. Threat Detection

The trained model is used to identify potentially malicious network activity.

Detected security events can then be recorded for further analysis and auditing.

### 5. Blockchain-Based Audit Trail

Blockchain-inspired hash verification is used to improve the integrity of security event records.

Each recorded security event can be associated with a cryptographic hash, allowing the integrity of the stored information to be verified.

### 6. Security Monitoring

The system provides a monitoring interface for viewing threat detection results and associated security information.

## 📊 Dataset

The project uses the **KDD Cup 99 dataset**, a widely used benchmark dataset for network intrusion detection research.

The dataset contains network connection records with features describing different aspects of network traffic.

The dataset is used to train and evaluate the machine learning-based threat detection model.

## 🤖 Machine Learning

### Random Forest

Random Forest is an ensemble machine learning algorithm that combines multiple decision trees to perform classification.

In this project, Random Forest is used to classify network traffic and identify potentially malicious activity.

---

## 🔐 Blockchain-Based Audit Trail

The blockchain-based component focuses on maintaining the integrity of detected security events.

The basic concept is:

```text
Security Event
      ↓
Event Record
      ↓
Hash Generation
      ↓
Blockchain / Audit Record
      ↓
Hash Verification
      ↓
Integrity Confirmation
```

This approach helps identify whether a stored security record has been modified after it was recorded.
